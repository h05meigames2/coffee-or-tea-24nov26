A single letter for coffee — the first thing the day reaches for. One letter, one drink, no explanation.

## Run it

```sh
python3 main.py
```

This writes the letter `A` to `entry.txt` inside the directory given by
`MAKEFUN_OUTPUT_DIR` (defaults to `/output`), with no trailing newline.
